Panduan Singkat

Ekor gerakan mouse + tampilan tombol keyboard & mouse untuk live stream (OBS dan software lain). Versi 1.4.2.

1. Mulai dalam 3 langkah

  1. Jalankan AimTrail.exe. Ikon muncul di system tray (dekat jam) dan panel terbuka di browser.
  2. Di OBS: Sources > + > Browser. Isi Width/Height sesuai kanvas OBS (mis. 1920 x 1080) dan FPS 60. Disarankan: centang Local file lalu pilih file dari kartu Anti-putus di panel (atau tray > File OBS anti-putus). Dengan cara ini source tetap tersambung walau OBS dibuka sebelum AimTrail. Alternatif: tempel URL dari tabel di bawah.
  3. Atur tampilan di panel. Perubahan langsung terlihat di OBS, tanpa refresh.
OverlayURL Browser SourcePanel pengaturan
Ekor gerakan mousehttp://localhost:8765/overlay.html/panel.html
Tombol keyboard + mousehttp://localhost:8765/keys.html/keys-panel.html

Tidak perlu mengetik URL: klik kanan ikon tray > Salin URL overlay. Pakai dua Browser Source terpisah agar bebas diatur posisi dan ukurannya.

2. Ekor gerakan mouse

  • Mode normal: tahan klik kiri lalu gerakkan mouse, ekor muncul dan memudar. Lepas klik, ekor hilang. Tanpa klik, overlay diam.
  • Mode selalu aktif: tekan tombol Selalu aktif di bawah preview (atau centang di grup Pemicu) agar ekor mengikuti gerakan mouse kapan saja tanpa menekan apa pun. Tekan lagi untuk mematikan. Paling nyaman dipadukan dengan Titik terkunci di tengah.
  • Tombol cepat saat bermain: menu tray Ekor mouse selalu aktif, atau buka http://localhost:8765/api/always?on=toggle (mis. dari Stream Deck).
  • Pilih Preset (Neon Biru, Api, Laser Merah, Matrix, Pelangi, dll.), lalu sesuaikan warna, lama ekor, tebal, glow, dan titik kepala.
  • Titik terkunci di tengah: Gerakan > Saat mencapai tepi layar > Titik terkunci di tengah. Titik diam, ekor yang bergerak.
  • Sensitivitas: samakan dengan sensitivitas game agar panjang ekor sesuai gerakan nyata.
  • Tombol pemicu bisa diganti (klik kanan, tengah, Mouse 4/5), dengan mode tahan atau toggle.
  • Garis tepi overlay, latar grid, dan watermark ada di grup Latar (opsional) dan Watermark.

3. Tombol keyboard + mouse

  • Menampilkan tombol yang sedang ditekan: 1 2 3 4, Q W E R, A S D F G, SHIFT Z C V, TAB, CTRL, ALT, SPACE ditambah mouse (klik kiri, kanan, tengah, scroll, thumb depan dan belakang).
  • Seret tombol di preview untuk memindahkannya. Klik tombol untuk mengubah teks, ukuran, atau menghapusnya. Gunakan Tambah tombol untuk tombol lain (A-Z, 0-9, F1-F12, panah, dll.).
  • Pilih preset layout (FPS lengkap, WASD minimal, hanya mouse) dan preset gaya (Neon, Flat, Keycap 3D, Kaca).
  • Atur warna, glow, animasi tekan, ukuran, posisi papan, dan sembunyikan otomatis saat tidak dipakai.

Privasi: server hanya meneruskan tombol yang ada di layout-mu. Ketikan lain (password, chat, dll.) tidak pernah dikirim ke overlay dan tidak disimpan.

4. Menu ikon tray (klik kanan)

  • Buka panel ekor mouse / keyboard + mouse (klik dua kali ikon = panel ekor mouse), dan Buka panduan.
  • Ekor mouse selalu aktif (tanpa klik) untuk menyalakan/mematikan mode selalu aktif, dan Salin URL overlay untuk langsung ditempel ke OBS.
  • Jalan otomatis saat Windows menyala, Akses dari PC lain (LAN), Pembaruan, Buka folder pengaturan, Tentang, Keluar.
  • Pembaruan: AimTrail memeriksa versi baru otomatis. Jika ada, muncul notifikasi dan spanduk di panel. Klik Pasang (overlay terputus beberapa detik lalu menyala sendiri).

5. Dua PC (game di PC A, OBS di PC B)

  1. Di PC A, aktifkan Izinkan akses dari PC lain (LAN) pada menu tray.
  2. Di OBS pada PC B, pakai URL http://IP-PC-A:8765/overlay.html (IP muncul di notifikasi tray).
  3. Izinkan port 8765 di firewall PC A. Gunakan hanya di jaringan yang kamu percaya.

6. Tips agar ringan dan mulus

  • Browser Source: centang Use custom frame rate dan isi 60 (default sebagian versi OBS hanya 30 FPS).
  • OBS > Settings > Advanced: aktifkan browser source hardware acceleration, lalu restart OBS.
  • Terasa berat? Panel > Performa & kehalusan > Kualitas render = Ringan, atau matikan Glow.
  • Tambahkan ?debug=1 di akhir URL overlay untuk melihat FPS dan jumlah data per detik.
  • Memakai kedua overlay? Watermark otomatis hanya tampil di satu overlay.

7. Pemecahan masalah

GejalaSolusi
Panel tertulis "mode simulasi"Raw Input gagal atau bukan Windows. Lihat aimtrail.log (tray > Buka folder pengaturan).
Tidak bereaksi saat mainJika game berjalan sebagai Administrator, jalankan AimTrail sebagai Administrator juga.
Pengaturan tidak berubah di OBSKlik kanan Browser Source > Properties > Refresh cache of current page.
Ekor muncul terus padahal tidak menekan apa punMode Selalu aktif sedang NYALA. Matikan lewat tombol di panel atau menu tray.
Pembaruan gagal atau tidak munculPastikan internet aktif. Menu tray > Pembaruan > Periksa pembaruan sekarang. Bila gagal, unduh manual di halaman Releases GitHub.
OBS dibuka sebelum AimTrail, source kosong / errorGanti source ke mode Local file (kartu Anti-putus di panel). Untuk source berupa URL: klik kanan source > Refresh, atau centang Refresh browser when scene becomes active.
Overlay kosong di OBSBuka URL di browser biasa; pastikan ikon AimTrail ada di tray.
Port 8765 dipakai aplikasi lainUbah "port" di settings.json, jalankan ulang, lalu ubah URL di OBS.
SmartScreen / antivirus memberi peringatan.exe tidak bertanda tangan digital dan membaca input global. Kecualikan file AimTrail.exe; jangan mematikan antivirus.

8. Catatan

  • AimTrail hanya membaca input lewat Raw Input standar Windows (tanpa hook atau injeksi ke game). Kebijakan tiap anti-cheat berbeda; untuk game kompetitif, cek aturan resminya.
  • Pengaturan tersimpan di %APPDATA%\AimTrail (config.json, keys.json, settings.json).
