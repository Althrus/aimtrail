URL untuk OBS

  1. OBS → Sources → + → Browser, tempel URL di atas.
  2. Isi lebar/tinggi sesuai kanvas OBS (mis. 1920 × 1080), FPS 60.
  3. Letakkan di atas Game Capture. Pengaturan di panel ini langsung berlaku.

Anti-putus untuk OBS (disarankan)

Di Browser Source OBS centang Local file, lalu pilih file di bawah. Overlay tetap tersambung walau OBS dibuka sebelum AimTrail atau AimTrail dimulai ulang, tanpa perlu menghapus dan membuat source lagi.
