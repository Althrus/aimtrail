Anti-putus untuk OBS (disarankan)

Di Browser Source OBS centang Local file, lalu pilih file di bawah. Overlay tetap tersambung walau OBS dibuka sebelum AimTrail.

Cara membaca

Kecepatan: seberapa cepat tangan menggerakkan mouse (cm/dtk butuh DPI yang benar). CPS: klik per detik. Tahan klik: lama menahan tombol. Stabilitas: 100% = gerakan lurus/halus, makin turun = makin bolak-balik/goyang (indikator kasar, bukan skor resmi).
